4. Grafo y cobertura de ramas (Java)
Analiza el método y el grafo de flujo de control. Cada par de las opciones representa (monto, saldo).
static String autorizar(int monto, int saldo) {
    if (monto <= 0) return "INVALIDO";
    if (monto > saldo) return "INSUFICIENTE";
    return "APROBADO";
}
Grafo: 1 → 2; 2 Sí → 3 → 7; 2 No → 4; 4 Sí → 5 → 7; 4 No → 6 → 7.
¿Qué conjunto mínimo de pruebas permite recorrer todas las ramas de las dos decisiones?
A. (10, 100) y (50, 100).
B. (0, 100) y (-10, 100).
C. (-10, 100), (150, 100) y (50, 100).
D. (150, 100) y (200, 100).
Tu elección: A | Correcta: C | 0 puntos
Se necesitan tres pruebas: (-10, 100) recorre 1 → 2 → 3 → 7 y retorna INVALIDO; (150, 100) recorre 1 → 2 → 4 → 5 → 7 y retorna INSUFICIENTE; (50, 100) recorre 1 → 2 → 4 → 6 → 7 y retorna APROBADO. Así se recorren las salidas verdadera y falsa de ambas decisiones. La complejidad ciclomática es 2 decisiones + 1 = 3.
